# The recipes: named patches to start from. compose.py reads this file
# once, when it loads: recipe gives a recipe as it is or moved by deltas,
# --recipes lists them all, and a timeline's recipe statement expands to the
# raw patch lines (compose.py --expand), so no record needs this file. op
# still writes any patch at all. See docs/INSTRUMENT.md,
# Patches, recipes and the synthesis repertoire.
#
# Host template blocks and recipe use lines are described at the end of this
# file and in docs/INSTRUMENT.md, Bounded macros and templates. They compile to raw
# mod/LFO headers; existing recipes remain independent of unused templates.
#
# Spectral guide: for ideal sine-on-sine PM without feedback, carrier fc and
# modulator fm produce sidebands at |fc +/- n*fm|. Their signed amplitudes
# depend on the Bessel coefficients J_n(I), where I is the instantaneous
# modulation index in radians (Jacobi-Anger expansion: https://dlmf.nist.gov/10.12).
# The note's carrier frequency need not be the loudest partial. Envelopes and
# velocity change I over time; coincident partials can add or cancel. Feedback,
# other waveforms, operator routes and processing need their own measurement.
# These descriptions suggest a starting timbre, not a fixed harmonic spectrum.
#
# A recipe is a block of lines, each starting with its kind:
#   recipe NAME              the block's start: NAME is letters, digits, . _ -
#   carrier KEY=VALUE ...    the carrier's op arguments (operator 0)
#   modulator KEY=VALUE ...  the modulator's op arguments (operator 1)
#   route OPS CARRIERS FROM>TO:WEIGHT ...
#                            a routed recipe : the timeline's route
#                            statement without its patch name; OPS 2 to 4,
#                            CARRIERS an odd bit mask (operator 0 is always a
#                            carrier: the leveller moves its level), each edge
#                            once, WEIGHT 1 to 1024 in 1/256 (256 is unity)
#   op N KEY=VALUE ...       operator N's op arguments, under a route only:
#                            one line for each N from 2 to OPS - 1
#   note TEXT                what it is, ending with the piece that tested it;
#                            more note lines go on after one space
#   tags WORD ...            words analyze.py search --tag finds it by; this file
#                            owns the vocabulary, compose.py skips it
#   describe_note MILLIHZ    optional description pitch, above 0 and below 24000000;
#                            metadata only, before prose pitch and the A4 default
# Tag meanings: keys/bell/wind/pad/bass/chip/drum are sound families; piano,
# pluck, reed, voice and cymbal name their sounds. noise means a wave-4 operator
# or a modulator fed back at least 3 rad; it is not a spectral-flatness threshold.
# layer means a partner recipe or several voices; sweep means a pitch curve/step.
# A KEY is any argument of op in compose.py, in op's units: ratio a multiple
# of the note's frequency, level and s in dB below peak, index and fb in
# radians, vel in 1/256, a, d and r in ms, ks_break in Hz and ks_slope in dB an
# octave, wave 0 to 11, rs in steps 0 to 7, fixed in Hz, phase in
# degrees, 0 to 359.994 (360 is refused, not wrapped to 0, and a delta stops
# at either end), and free 0, 1 or 2, and any
# argument op gains; one left out takes op's default. The engine reads no
# index, fb or key scaling on the carrier and no level on the modulator, so a
# recipe sets none of them; under a route it reads a level only on a carrier
# and an index or key scaling only on an operator that feeds an edge, so a
# routed recipe sets those only there, and each of its operators reaches a
# carrier through the edges. A VALUE is a plain decimal number within its
# field's range (LIMITS in compose.py): a whole number where op's default is
# one (vel, a, d, r, wave, rs, free), else a whole number or digits with a point,
# kept as written (17 and 17.0 print differently in --recipes). A line whose
# first character other than a space is # is a comment; blank lines are
# ignored. A fault stops compose.py with this file's name and the line.

# regression host templates: first matching case, all targets fit or the call refuses.
# target roles are present outgoing-PM modulators, two numbered modulators or
# carriers, and brightest (largest ratio; lower operator breaks a tie).
# Depths are raw modulation matrix integers. All smoothing shifts default to3. These are
# provisional  values, not eight macros with eight independent curves.
# use NAME applies a template to a recipe; no template row enters a timeline.
template HARM
case default
macro HARM 0 unipolar
target pitch.modulators 1200
end

template DTUN
case default
macro DTUN 1 bipolar
target pitch.mod0 25
target pitch.mod1 -25
end

template MIX
case vector
macro MIX 2 unipolar
target vector_x 32768
case default
macro MIX 2 bipolar
target level.car0 120
target level.car1 -120
end

template Timbre
case default
macro Timbre 3 unipolar
target index.modulators 2048
end

template EXPR
case filter
lfo 0 5000 0 0 0 0 0
macro Wheel 0 unipolar
target lfo_pitch 50
macro Pressure 1 unipolar
target index.brightest 1024
macro Slide 4 unipolar
target cutoff 1200
case default
lfo 0 5000 0 0 0 0 0
macro Wheel 0 unipolar
target lfo_pitch 50
macro Pressure 1 unipolar
target index.brightest 1024
macro Slide 4 unipolar
target index.brightest 2048
end
